CVE: CVE-2026-43726

Severity: High

Affected: WebKit (Safari) - AudioBufferSourceNode Use-After-Free

Fix Commit: a7e4fdb95450

Vulnerability: AudioBufferSourceNode caches raw pointers into AudioBuffer's channel data when setting node.buffer. If the buffer is set before calling start(), the ArrayBuffer backing store is not pinned (not made non-detachable). An attacker can detach it via structuredClone with transfer, drop the reference, trigger GC to free the backing store, then start playback — causing a use-after-free read from freed memory.

Exploit Steps:

1. Create AudioContext + AudioBuffer
2. Set buffer on AudioBufferSourceNode (before start - no pin applied)
3. Get channel ArrayBuffer backing store
4. structuredClone with transfer to detach the backing store
5. Drop clone reference + trigger GC (frees the memory)
6. Set loop=true, playbackRate=0, start playback
7. Render audio - reads from freed memory (UAF crash)
