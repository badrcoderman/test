CVE-2026-43705 - TransformStream Type Confusion

CVE: CVE-2026-43705 | Severity: Critical

Component: WebCore Streams - TransformStream.cpp

Fix: 8fd92b1021d3

Bug: createInternalTransformStream iterates its result array via the JS iteration protocol. If Array.prototype[Symbol.iterator] is overridden, an attacker can substitute arbitrary objects for the readable/writable stream entries. C++ then dereferences them as JSReadableStream*/JSWritableStream* → type confusion → controlled memory read/write.

Steps:

1. Override Array.prototype[Symbol.iterator] to return fake objects

2. Create new TransformStream() → triggers createInternalTransformStream

3. Internal builtin returns [startResult, readable, writable] array

4. Poisoned iterator replaces readable/writable with attacker objects

5. C++ does dynamicDowncast<JSReadableStream>(fake)->wrapped() → type confusion

6. Access .readable / .writable → vtable call on attacker data
